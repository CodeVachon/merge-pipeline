Inspect configuration

Usage: merge-pipeline config <COMMAND>

Commands:
  path    Print the workflow directory that would be used, and which rule chose it
  doctor  Validate the workflow files: JSON, names, regexes, ordering, and branch matches
  init    Create the workflow directory with the default workflow files
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
